HollyUpdate — Archive Index

Indeks berkas untuk arsip aplikasi Android berbasis Flutter.

Halaman ini *bukan* aplikasi Android yang diubah jadi web dan *tidak* menjalankan kode native / Dart. Ini adalah katalog untuk melihat isi arsip, pratinjau aset media, dan mengunduh berkas.

🔗 Demo (GitHub Pages)

Buka lewat browser:
`https://username-kamu.github.io/nama-repo-kamu/`

> Ganti username-kamu dan nama-repo-kamu sesuai repo lu.

✨ Yang Bisa Dilakukan Di Sini

- *Galeri Media* - Lihat langsung gambar, video, dan audio tanpa download
 - Gambar: banner.jpg, logo.png, qris.jpg, login.png, dll
 - Video: splash.mp4, landing.mp4, banner.mp4, bug.mp4
 - Audio: d.mp3, k.mp3, r.mp3, s.mp3, t.mp3
- *Cari Berkas* - Cari nama file / path dari 600+ berkas arsip
- *Buka Berkas* - Klik nama file untuk buka / download file tersebut

📱 Cara Akses Kayak Aplikasi (iPhone / Android)

1. Buka link GitHub Pages di atas lewat Safari (iPhone) / Chrome (Android)
2. Pencet Share > Add to Home Screen / Tambah ke Layar Utama
3. Sekarang bisa dibuka kayak aplikasi dari Home Screen

Catatan: Yang kebuka adalah versi web katalog ini, bukan APK-nya.

🤖 Cara Install APK Aslinya (Android Only)

APK / file arsip Android hanya bisa jalan di HP Android, tidak bisa di iPhone.

1. Download file APK dari repo ini
2. Di HP Android, buka file-nya
3. Izinkan Install dari sumber tidak dikenal kalau diminta
4. Pencet Install

🛠️ Cara Pakai Secara Lokal

Kalau mau jalanin di laptop / HP tanpa GitHub Pages:

1. Ekstrak seluruh isi ZIP ke satu folder
2. Pastikan index.html satu folder dengan folder assets/, res/, lib/, dll
3. Buka index.html lewat browser

Kalau file-nya kepisah folder-nya, preview gambar / video-nya gak bakal muncul.
